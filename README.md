## Prediction task

This project uses supervised regression to predict hourly bicycle rental demand in Seoul.

- Target: Rented Bike Count.
- Inputs: weather, time and calendar information.
- Purpose: support bicycle availability planning.

Research question: How accurately can machine learning models predict hourly bicycle rental demand using these features?

## Dataset

- Name: Seoul Bike Sharing Demand.
- Source: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/560/seoul+bike+sharing+demand).
- Dataset citation: [Seoul Bike Sharing Demand (2020)](https://doi.org/10.24432/C5F62R).
- Local file: `data/raw/SeoulBikeData.csv`.
- Size: 8,760 records and 14 columns, including the target.
- Licence: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
- Accessed: 3 October 2026.

The original CSV is kept unchanged. Dataset attribution and the licence apply to the data.
